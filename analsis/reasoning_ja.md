# 推奨案の計算方法と用語

対象は、Airbnb手数料・管理会社費用・清掃消耗品費を除外した**14戸案**です。英語の提出・共有用説明は [recommendation_en.md](recommendation_en.md) を参照してください。金額はすべてCADです。

## 推奨する物件構成

| 地域 | 物件 | 戸数 | 取得費用・家具込みの必要資金 |
| --- | --- | ---: | ---: |
| Downtown Eastside | 1寝室コンド | 6 | 3,518,570 |
| Downtown | 1寝室コンド | 5 | 3,446,188 |
| West End | 2寝室コンド | 2 | 1,847,349 |
| Kitsilano | 1寝室コンド | 1 | 689,238 |
| **合計** | **1寝室12戸、2寝室2戸** | **14** | **9,501,345** |

## 1. 購入に必要な資金

```text
1戸の必要資金 = 想定購入価格 × 1.04 + 家具代25,000
```

4%は取得費用の仮定です。例えばDowntown Eastsideでは、`539,835 × 1.04 + 25,000 = 586,428.40` となります。

購入価格は、GVRの東西別・物件タイプ別の代表価格に寝室数の倍率を適用した推定値です。個別物件の実売価格や売出価格を確認したものではありません。1寝室コンドの倍率は0.85、2寝室は1.15で、プロジェクト独自の仮定です。

## 2. 年間売上と固定費

年間売上は、同じ「地域 × 物件タイプ × 寝室数」に属する掲載物件の推定年間売上の中央値を使います。

```text
コンド1戸の年間固定費
  = 購入価格 × 固定資産税率0.3%
    + 管理組合費500 × 12か月
    + 保険2,000
    + ライセンス・登録費1,500

今回の年間収益 = 推定年間売上 − 年間固定費
```

Downtown Eastsideの例：

```text
固定費 = 539,835 × 0.003 + 6,000 + 2,000 + 1,500
       = 11,119.505

年間収益 = 49,140 − 11,119.505
         = 38,020.495
```

固定費も実際の見積もりではなく仮定です。管理組合費は管理会社への運営代行費とは別の費用なので、このシナリオでも残しています。

## 3. 比較用利回りと順位

```text
比較用利回り = 今回の年間収益 ÷ 1戸の必要資金
```

| 地域・物件 | 必要資金／戸 | 推定年間売上／戸 | 年間固定費／戸 | 年間収益／戸 | 比較用利回り |
| --- | ---: | ---: | ---: | ---: | ---: |
| Downtown Eastside・1寝室 | 586,428 | 49,140 | 11,120 | 38,020 | 6.48% |
| Downtown・1寝室 | 689,238 | 51,788 | 11,416 | 40,372 | 5.86% |
| West End・2寝室 | 923,674 | 59,953 | 12,092 | 47,861 | 5.18% |
| Kitsilano・1寝室 | 689,238 | 46,221 | 11,416 | 34,805 | 5.05% |

例えばDowntown Eastsideは、`38,020.495 ÷ 586,428.40 ≒ 6.48%` です。表は四捨五入していますが、選定と合計には丸める前の値を使っています。

## 4. 戸数の決め方

比較用利回りの高い候補から、次の条件を守って整数戸ずつ選びました。

- 総予算1,000万以下。
- 1地域への投入資金400万以下（総予算の40%）。
- 比較対象20件以上の区分を採用。
- 1区分の購入戸数は、比較対象件数の10%以下。端数は切り捨て。

| 地域 | 選定理由・上限 |
| --- | --- |
| Downtown Eastside：6戸 | 7戸では約411万となり、地域上限400万を超える |
| Downtown：5戸 | 6戸では約414万となり、地域上限を超える。他の寝室数の候補も、残りの地域枠では買えない |
| West End：2戸 | 比較対象25件なので、`floor(25 × 10%) = 2戸` が上限 |
| Kitsilano：1戸 | 残り予算で1戸購入。その後の残額では、追加の適格候補を買えない |

この方法は「高利回り順に買う貪欲法」です。年間収益の合計が最大になる組み合わせだと数学的に証明したものではありません。

## 5. 全体の数字

```text
購入価格合計                    8,799,370
取得費用：購入価格の4%             351,974.80
家具代：25,000 × 14戸              350,000
必要資金合計                    9,501,344.80
予算残額                          498,655.20

年間売上合計                      719,907
年間固定費合計                   −159,398.11
今回の年間収益                    560,508.89

比較用利回り = 560,508.89 ÷ 9,501,344.80 ≒ 5.90%
総予算に対する比率 = 560,508.89 ÷ 10,000,000 ≒ 5.61%
```

5.90%はAirbnb手数料・管理会社費用・清掃消耗品費を引く前の数字です。所得税・修繕積立・大規模修繕等も含まず、完全な投資利回りではありません。区分中央値の合計は、ポートフォリオ全体の期待値や中央値と同じではありません。

## 「比較対象」とは

同じ「地域 × 物件タイプ × 寝室数」に分類されたAirbnb掲載物件です。集計では、過去1年にレビューがある住戸全体の貸出掲載を対象としています。

例えば「Downtown Eastside・1寝室コンド」の比較対象152件とは、その区分の掲載152件から売上の中央値を計算したという意味です。**購入可能な売出物件が152件あるという意味ではありません。** 広さ、建物の質、立地条件まで一致した比較でもありません。

| 今回の区分 | 比較対象件数 |
| --- | ---: |
| Downtown Eastside・1寝室コンド | 152 |
| Downtown・1寝室コンド | 374 |
| West End・2寝室コンド | 25 |
| Kitsilano・1寝室コンド | 33 |

## 「地域上限40%」はどこから来たか

既存の [src/portfolio.py](../src/portfolio.py) の `build_portfolio(..., max_per_hood=0.4)` と、[docs/decision_log.md](../docs/decision_log.md) の決定項目5に記載されています。

**法律や課題の必須条件として確認した数字ではなく、このプロジェクトが設定していた分析上の仮定です。** 今回はその設定を引き継ぎました。20件以上の最低比較件数も、頑健性を意識して分析側が置いた仮定です。これらを変えると、推奨する地域・戸数も変わり得ます。
